# おでかけマップ

![おでかけマップのスクリーンショット](screenshot.webp)

地図にピンを立てて、行きたい・行ってよかったスポットを記録・共有し、スポットをつないだおでかけルートを作れるWebアプリです。行きたいお店をSNSやメモアプリに散らばらせることなく、地図上でまとめて管理するために作成しました。

- **デモ**：https://gs2026-arakawa.sakura.ne.jp/kadai10_proto/
- **テストアカウント**：ユーザー名 `demo` / パスワード `demo`

以前 JavaScript × Firebase で作成したアプリを、React × PHP × MySQL で一から作り直しました。作り直す際に、ルート作成機能（Google Maps Directions API）を新たに加えました。

---

## 主な機能

### スポット（ピン）

- 地図をクリックしてピンを登録・編集・削除
- 本文を「テキスト」と「画像」のブロックで組み立て、ドラッグ＆ドロップで並べ替え
- カテゴリ・タグの付与と、カテゴリによる絞り込み
- 「下書き」と「公開」の切り替え（下書きは本人にだけ表示）

### ルート

- 登録したピンを経由地にしたルートを作成し、経由地の順番をドラッグ＆ドロップで並べ替え
- 移動手段（徒歩・車・自転車・公共交通機関）を選ぶと、Directions API で経路を計算して地図に描画

### アカウント

- ユーザー登録・ログイン・ログアウト（セッション認証）
- 自分が登録したピンとルートだけを編集・削除できる

### 地図表示

- 地図スタイル（モノクロ／通常）の切り替え

## 使用技術

| 分類 | 技術 |
|---|---|
| フロントエンド | React 19 / Vite 8 / dnd-kit / ESLint |
| バックエンド | PHP 8.3（フレームワークなし・PDO） |
| データベース | MySQL 8.0 |
| 外部API | Google Maps JavaScript API / Directions API |
| インフラ | さくらのレンタルサーバー（本番）／ MAMP（ローカル開発） |

### システム構成

```
frontend/ (React + Vite)  ──fetch(JSON, Cookie)──▶  backend/ (PHP API)  ──PDO──▶  MySQL
        │
        └── Google Maps JavaScript API / Directions API
```

### ディレクトリ構成

```
.
├── frontend/          # React アプリ
│   └── src/
│       ├── api/        # バックエンドAPI・Google Maps の呼び出し
│       ├── components/ # 画面コンポーネント
│       └── hooks/      # 確認ダイアログ・アラート用のカスタムフック
├── backend/           # PHP API
│   ├── auth/           # 登録・ログイン・ログアウト・ログイン中ユーザーの取得
│   ├── pins/           # ピンのCRUD・画像アップロード
│   ├── routes/         # ルートのCRUD
│   ├── categories/     # カテゴリ一覧
│   ├── tags/           # タグ一覧
│   └── config/         # DB接続・CORS・セッション・.env読み込み
├── uploads/pins/      # アップロードされた画像
└── db.sql             # テーブル定義
```

## DB設計

| テーブル | 内容 |
|---|---|
| `users` | ユーザー |
| `pins` | スポット（位置・カテゴリ・公開状態） |
| `pin_blocks` | ピン本文のブロック（テキスト／画像、並び順） |
| `categories` / `tags` / `pin_tag` | カテゴリ、タグ、ピンとタグの中間テーブル |
| `routes` / `route_stops` | ルートと経由地（並び順） |

## 工夫した点

### セキュリティ

- **所有者チェック**：更新・削除の SQL を `WHERE id = :id AND user_id = :user_id` の形にして、ログイン中ユーザーの投稿しか変更できないようにしました。下書きの取得も本人に限定しています。
- **SQLインジェクション対策**：すべてのクエリでプリペアドステートメント（PDO）を使っています。
- **パスワード**：`password_hash` / `password_verify` でハッシュ化して保存・照合しています。
- **画像アップロード**：拡張子ではなく MIME タイプでファイル形式を判定し、JPEG・PNG・GIF・WebP の2MB以下だけを受け付けます。保存時のファイル名はサーバー側で生成しています。

### 開発環境と本番環境の切り替え

- API の URL は Vite の環境変数（`.env.local` / `.env.production`）に、ビルド時のパスは `vite.config.js` の `base` に分けて設定し、コードを変更せずに環境を切り替えられるようにしました。
- API キーや DB の接続情報は `.env` に分けて、リポジトリには含めていません。

### 使いやすさ

- ピン本文を自由な順番で組み立てられるブロック形式にし、経由地とあわせて dnd-kit でドラッグ＆ドロップで並べ替えられるようにしました。
